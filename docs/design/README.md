# Claude Design参照資料

`医療業務支援タブレットアプリ.html` が元のエクスポート。埋め込みアセットを保持するため、元HTMLは整形対象から除外する。

`claude-design-sources.json` は元HTMLのmanifestをJSONとして読み、JavaScriptアセットをbase64復号・gzip展開した後、`window.__MS_SOURCES` のJSONオブジェクトだけを抽出した参照用スナップショット。バンドル内のJavaScriptは実行していない。31ファイルの内容を元のパスをキーとして保持する。アプリからはimportせず、実装時にTypeScriptと既存の構成へ移植する。

## 参照箇所

| JSON内のキー（`vue-app/src/` 以下）                      | 用途                                                                                      |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `components/widgets/*.vue`                               | 14種類の表示と共通枠WidgetCard。実装順とサイズは `../implementation-plan.md` の表を参照   |
| `data/master.js`                                         | 病棟c5e・g6w・icu、職種doctor・pharm・ce、コンポーネント定義、4画面の初期配置             |
| `data/patients.js`                                       | 病棟別の架空患者、バイタル・症状・体重・水分出納・現病歴・検査値・薬剤・機器などのfixture |
| `components/LayoutGrid.vue`、`components/WidgetHost.vue` | 定義サイズでのグリッド描画、種類に応じたSFC選択                                           |
| `views/LayoutEditorView.vue`                             | 一覧・概要・プレビュー・配置ガイド・参照のみの表示                                        |
| `store/app.js`、`utils/helpers.js`                       | 初期シーン、画面選択優先順位、衝突・配置補正・差分判定                                    |
| `plugins/vuetify.js`、`App.vue`                          | 色、共通スタイル、基準画面寸法                                                            |

患者fixtureは表示用サンプルで、年齢・残り日数・評価値などを文字列でも持つ。今後は表示モデルを型付けし、日時の導出には共通JSTヘルパーを使う。臨床用の基準や計算式として採用しない。

## 移植時に変える点

- ストアの `view` 切替はvue-routerへ移す。単一のreactiveストアはデータ取得・UI設定・局所状態に分ける。
- デザインでは職員IDと職種IDが同じ値だが、アプリでは分離する。シーン初期化時の病棟自動変更を通常ログインに持ち込まない。
- 新規追加は決定まで下書きとし、取消で破棄する。元コードの追加直後の登録は採用しない。
- 定数は `LIMITS`、日時はutilsのJSTヘルパーを利用する。関数宣言をアロー関数へ変え、provide/injectを使う場合はInjectionKeyで型付けする。
- プレビューの与薬・点検は操作不可にする。固定の縮小率と画面寸法を全端末に適用しない。
- 元ソースの実行用ローダー、ベンダーコード、シーン一覧ラッパーはアプリに組み込まない。

P0では参照資料の整理まで完了。型付きfixture、レジストリ、表示コンポーネントの実装はP1以降で行う。

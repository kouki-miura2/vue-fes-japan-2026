## PWA

- production buildのmanifest解析エラーとChromeのinstallabilityErrorsがいずれも0件。
- 通常192px・512px、maskable512px、Apple180pxのPNGとfavicon SVGがbuild成果物にあることを確認。
- 専用の一時ChromeプロファイルでCDPの `PWA.install`（ログイン画面のURLから）、`PWA.launch` を使い、ウィンドウ表示の設定で起動したページの `matchMedia('(display-mode: standalone)').matches` がtrue、ログイン画面が表示されることを確認。確認後に `PWA.uninstall` で検証用アプリを削除。
- 通常利用ではChrome・Edgeのブラウザメニュー、iPadの共有メニューを利用する。配信にはHTTPSが必要で、ローカルはlocalhost／ループバックを使う。インストールの要件は [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) を参照。
- WindowsのChromeで検証した。iPad／Android実機でのインストールと実タッチは未検証。オフライン起動、サーバー認証、実カード、病院内の設定共有は今回の対象外。
